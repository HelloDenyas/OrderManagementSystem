# Užsakymų valdymo sistema

React ir TypeScript administravimo sąsaja, sukurta naudojant Vite.

## Komandos

- `npm run dev` – paleidžia kūrimo serverį.
- `npm run build` – patikrina TypeScript ir sukuria produkcinę versiją.
- `npm run lint` – patikrina kodą su Oxlint.
- `npm run preview` – lokaliai peržiūri produkcinę versiją.
